# Plots

Figures generated by the scripts in [`../scripts/`](../scripts/). Every figure
recomputes its values from the live model, so it cannot drift from the code. The
generated `*.png` files are git-ignored; regenerate them with the commands below
(after `uv sync --group viz`).

## The headline: what the simulation did

**[`neural_summary.png`](neural_summary.png)** — the consolidated end-to-end view of
one model run, following neural activity to a predicted nanometre displacement:

1. **Activity** — the E/I limit cycle and the synchrony `r(t)` it produces.
2. **The bridge** — the reduced `NeuralState` (`s`, `f_c`, `σ_t`, mean rate, `Q`,
   and the illustrative coherent-neuron count `s·N`) and the arrow to the boxed
   **predicted Δz**, with the `coherent × jitter-survival` breakdown.
3. **Jitter survival** — `exp(−2π²f²σ²)` across frequency, with this run's content
   corner `f_c` marked and the surviving fraction read off.
4. **Decomposition** — the predicted Δz split into isotropic vs directional, coherent
   vs the incoherent pedestal, and before vs after the jitter low-pass.

```bash
uv run python scripts/plot_neural_summary.py            # generic cortex
uv run python scripts/plot_neural_summary.py --motor    # motor cortex (M1)
```

`neural_summary_motor.png` is the M1 variant: beta rhythm, an active directional
channel (the columnar Betz-cell contribution), and the sparse large-cell count.

## The other figures

| File | Script | Shows |
|---|---|---|
| `activity.png` | `plot_activity.py` | the E/I rhythm, synchrony `r(t)`, and the E(t) power spectrum |
| `dz_t.png` | `plot_displacement_timeseries.py` | the activity-driven `dz(t)` timeseries + its content-band spectrum |
| `survival.png` | `plot_survival.py` | content-band survival vs jitter, with the live run's operating point marked |
| `pass_space.png` | `plot_pass_space.py` | the (η, s) pass region and the crossover frontier |
| `min_eta.png` | `plot_min_eta.py` | the minimum detectable dilatation fraction η*(s) |
| `min_directional.png` | `plot_min_directional.py` | the directional bench targets β*(s,μ) and Q*(s,μ), with the g≤0 (no-rescue) regime |
| `resolution.png` | `plot_resolution.py` | the finest feasible voxel resolution vs (η, s) |

Regenerate all of them by running each script (they default their output here, into
`plots/`). Pass `-o <path>` to write elsewhere or `--show` to open a window.
