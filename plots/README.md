# Plots — motor cortex (M1)

Figures generated by the scripts in [`../scripts/`](../scripts/). Every figure
recomputes its values from the live model, so it cannot drift from the code. The
generated `*.png` files are git-ignored; regenerate them with the commands below
(after `uv sync --group viz`).

All figures are the **motor-cortex (M1)** story — a beta rhythm, the columnar Betz-cell
directional channel, and the honest through-skull detection verdict. They share one
visual system ([`../scripts/_style.py`](../scripts/_style.py)): a colourblind-safe
palette assigned by the *role* a quantity plays (direct / osmotic / vascular / floor),
consistent chrome, and a model-provenance footer on every figure.

## The headline story

The pipeline is **activity → NeuralState → displacement → detection**. Read the figures
in this order:

| # | File | Script | What it shows |
|---|---|---|---|
| 1 | `neural_summary.png` | `plot_neural_summary.py` | the whole pipeline on one page: the E/I beta cycle + synchrony, the reduced `NeuralState`, the jitter-survival curve, and the predicted Δz decomposition (isotropic + directional) |
| 2 | `transduction_chain.png` | `plot_transduction_chain.py` | **why 0.4 nm per neuron is not 520 nm**: the factor-by-factor cascade (`3Δr/r`, `f_cell·s`, `η·κ`, honest source factors, the Betz directional term) down to ~0.27 nm, and that signal against the ~184 nm floor |
| 3 | `mechanisms.png` | `plot_mechanisms.py` | the three co-existing mechanisms (direct / osmotic / vascular) vs the floor, and the band axis: only the vascular envelope clears the floor, but it is removed by the 1 Hz clutter high-pass — i.e. it is ordinary fUS, not the beta carrier |
| 4 | `budget.png` | `plot_budget.py` | the acoustic SNR budget: detectability vs skull two-way loss (per echo-SNR level, with the 0 dB wall and the honest demo point) and the axis ranking (skull loss dominates; the epoch is weak) |

## Regenerate

Each script defaults its output into `plots/`. Pass `-o <path>` to write elsewhere or
`--show` to open a window.

```bash
uv sync --group viz
uv run python scripts/plot_neural_summary.py
uv run python scripts/plot_transduction_chain.py
uv run python scripts/plot_mechanisms.py
uv run python scripts/plot_budget.py
uv run python scripts/plot_activity.py
uv run python scripts/plot_displacement_timeseries.py
```

## Which model call each figure reads

- **Steady resting beta** — `run_motor_cortex()` — the clean rhythm (neural summary,
  activity, and the dz(t) spectrum). Synchrony `s ≈ 0.97`, `f_c ≈ 20 Hz`.
- **The honest Gate-A demo** — `run_motor_demo()` — bursty beta with in-burst (p90)
  synchrony scoring and the honest source-physics factors (transduction chain,
  mechanisms, budget). This is the ≈ −60 dB content-band verdict.
- **A movement trial** — `run_motor_trial(MovementProfile(...))` — the desync→rebound
  arc for the dz(t) timeseries.

The direct term's directional (deviatoric Betz) share uses `deviatoric_eta` — the
constant-volume shape change is undrained, so it is **not** discounted by the
volumetric poroelastic `dilatation_eta`.
